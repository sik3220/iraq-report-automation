# 자동 분석 운영

- 예약 작업 설치·복구: `powershell -ExecutionPolicy Bypass -File deploy/install-tasks.ps1`

- 무료 수집: 매일 07:00~16:00 바그다드 시간, 1시간마다 실행
- 분석: 매일 09:00·12:00·15:00·16:30 바그다드 시간, PC 로그인 상태에서 실행
- 설정: deploy/analysis-settings.json, 월 1 USD / 일 0.25 USD
- 이 장부를 적용한 이후 이 프로젝트의 API 호출만 계산하며, 과거 호출·다른 앱·세금은 포함하지 않음
- GPT-5.5 Standard: 입력 1M 토큰 5 USD, 출력 1M 토큰 30 USD
  (2026-09-09 확인: https://developers.openai.com/api/docs/models/gpt-5.5)
- 호출 전 입력 UTF-8 바이트 기반 보수적 토큰 추정과 최대 출력 2048 토큰 비용을 예약
- 응답 usage 수신 후 실제 토큰 기반으로 정산, 캐시 할인은 무시해 보수적으로 계산
- 타임아웃·실행 중단·usage 누락은 예약액 유지, SDK 자동 재시도 없음
- 예산이 부족하면 pending 유지. 일 한도는 다음 날, 월 한도는 다음 달 복원
- 사용자에게 보이는 사용액은 보수적 추정. OpenAI 청구서와 다를 수 있음
- 분석 실패는 같은 기사에 당일 재호출하지 않음. 편집·분석 완료 기사는 자동 재분석하지 않음
- 서로 다른 날짜·본문·수치의 기사는 보존. 단순한 제목 단어 겹침으로 합치지 않음
- 추정 상한보다 작은 잔액은 사용하지 않을 수 있음. 지출을 늘리기 위해 자동 상향하지 않음
